# AGENTS.md — Easy Study Flashcards

## Project Overview

This project extracts chapters from a PDF (book format), identifies chapter
boundaries using DeepSeek AI, splits the PDF into per-chapter files, then
generates study flashcards (questions and answers) from each chapter using
DeepSeek.

## How It Works (Pipeline)

1. **Chapter detection**: The app reads the first ~30 pages of a PDF and
   **extracts their text** via `pypdf`. The text is sent to DeepSeek
   (`deepseek-v4-flash`) to identify chapter titles and their page numbers.
   It also inspects ~40 pages to find the first physical page of actual
   chapter content (vs. front matter).
2. **PDF splitting**: Using the DeepSeek response, `split_pdf_by_chapters()`
   splits the original PDF into individual chapter PDFs.
3. **Flashcard generation**: Each chapter PDF's text is extracted and sent to
   DeepSeek (`deepseek-v4-pro`) with a subject-matter prompt to generate Q&A
   flashcards as LaTeX documents.

## Dependencies (uv)

See the [uv documentation (llms.txt)](https://docs.astral.sh/uv/llms.txt) for

## Common Commands

```sh
# Install dependencies and create .venv
uv sync

# Run tests
uv run pytest

# Run tests with coverage
uv run pytest --cov=easy_study_flashcards

# Run the application
uv run python easy_study_flashcards/__init__.py

# Add a dependency
uv add <package>

# Add a dev dependency
uv add --dev <package>

# Update lockfile
uv lock

# Build with PyInstaller
uv run python build.py

# Build zipapp distribution
uv run python zip.py
```

## Environment

- Python 3.13+ (defined in `.python-version` and `requires-python`)
- A `DEEPSEEK_API_KEY` environment variable is required at runtime
  - Copy `.env.example` to `.env` and add your key, or export it directly
- The virtual environment lives at `.venv/` (auto-managed by uv)
- `uv run` automatically syncs the environment before running

## Test Assets

Test PDFs are downloaded from Google Drive via `gdown` when running tests
(see `conftest.py`). They are cached in `tests/assets/` (gitignored).

## Build & Distribution

- **`build.py`**: Uses PyInstaller (`--onefile`) to create a standalone
  executable from `easy_study_flashcards/__init__.py`.
- **`zip.py`**: Creates a `.pyz` zipapp archive using the virtual
  environment's Python interpreter.
